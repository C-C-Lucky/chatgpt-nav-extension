# ChatGPT 对话导航 (ChatGPT Navigation)

> 为 ChatGPT 网页版提供类似 DeepSeek 的右侧悬停式对话目录，支持提问与回答标题的嵌套导航。

## ✨ 功能特性

- **右侧短横杠，悬停展开**：收起时仅在右侧显示一条极简竖线，不干扰阅读；鼠标悬停时原地平滑展开导航面板。
- **提问 + 标题双层目录**：每条用户提问作为一级节点，回答中的 Markdown 标题（H1–H6）自动构建为可展开的嵌套子目录。
- **点击跳转与高亮**：点击任意节点，平滑滚动到对话对应位置，并短暂高亮目标区域。
- **滚动位置自动同步 (Scroll Spy)**：滚动阅读时，导航面板自动高亮当前正在阅读的提问或标题；如果高亮项在折叠的子级中，会自动展开其父级。
- **动态更新**：新消息发送或流式输出时，导航目录自动增量更新，不会打断当前操作。
- **深色 / 浅色主题自适应**。

## 🚀 安装方法

**目前仅支持通过 Chrome 开发者模式加载，尚未上架 Chrome 应用商店。**

1. 在本仓库的 [Releases](../../releases) 页面，下载最新版本的 `.zip` 文件。
2. 解压该 `.zip` 文件到一个你方便找到的文件夹（之后请不要删除或移动这个文件夹）。
3. 打开 Chrome，在地址栏输入 `chrome://extensions/` 并回车。
4. 在页面右上角，开启 **开发者模式 (Developer mode)** 开关。
5. 点击左上角的 **加载已解压的扩展程序 (Load unpacked)**。
6. 选择你刚才解压出来的那个文件夹（**注意：要选择包含 `manifest.json` 的那一层文件夹**）。
7. 插件就安装好了。打开或刷新 `https://chatgpt.com/`，右侧即可看到导航横杠。

## 🖱️ 使用方法

- **展开目录**：将鼠标移动到页面右侧的竖排短横杠上，导航面板会自动展开。
- **浏览层级**：点击提问条目旁的箭头，可以展开或折叠该回答下的标题子目录。
- **跳转**：点击任意提问或标题，页面会滚动到对应位置。
- **跟随阅读**：正常滚动页面，左侧导航会自动高亮当前阅读到的内容。
